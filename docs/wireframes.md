# Wireframe-Level Screen Specs

## 1. Main Feed
- Fullscreen 9:16 video viewport.
- Right action rail: like, comment, share, save, creator avatar + follow.
- Bottom metadata strip: title, tags, caption preview, sound/topic badge.
- Swipe vertical transitions with spring easing.

## 2. Explore Screen
- Top search bar with tabs (Videos, Users, Tags).
- Trending hero carousel.
- Topic clusters in masonry cards.
- Personalized "Because you watched" row.

## 3. Profile Screen
- Header: avatar, display name, bio, link in bio, follow/message buttons.
- KPI tiles: avg retention, total watch time, engagement score.
- Tabs: videos, playlists, tagged.
- Pinned videos row.

## 4. Creator Studio
- Upload wizard stepper: media -> trim -> thumbnail -> metadata -> publish.
- AI suggestions panel for hashtags/title optimization.
- Analytics cards and retention heatmap chart.

## 5. Admin Panel
- Moderation queue with risk score chips.
- Report drill-down with timeline and prior actions.
- Revenue dashboard with payout status.
- Feature flag toggles + manual trending override table.
