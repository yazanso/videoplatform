# Suggested Roadmap (Startup-Grade)

## Phase 1 (0-3 months) — Foundation
- Feed, upload, social graph, core analytics, moderation baseline.
- Initial ranking model with online learning hooks.
- Creator dashboard v1.

## Phase 2 (3-6 months) — Growth
- DMs infrastructure, collaborative playlists, live clips.
- Ad-serving MVP + revenue share accounting.
- Experimentation platform and growth loops (referral, streaks).

## Phase 3 (6-12 months) — Scale
- Multi-region serving + regional compliance rules.
- Advanced creator monetization (subs, gated content, storefront).
- Data warehouse + near-real-time cohort analytics.

## Bonus AI Features

- **AI Content Moderation:** multimodal policy model scoring every upload.
- **AI Thumbnail Optimizer:** predicts CTR-retention pair, suggests best frame.
- **Smart Recommendations:** sequence model for next-best-video prediction.
- **Auto Category Classification:** transcript + visual embeddings -> taxonomy labels.
- **Retention Heatmap Analytics:** second-by-second drop-off and replay heatmaps.
- **Viral Prediction Score:** early velocity + cohort spread + rewatch elasticity.
- **Creator Growth Score:** composite of consistency, retention, niche dominance.
